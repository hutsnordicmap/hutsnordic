# Client websites

This repo holds the free client websites (`sites/<site>/`) and their previews (`public/preview/<site>/`,
live at hutsnordic.fi/preview/<site>, never indexed). Before building or updating a client site, or answering a
client, read `docs/client-sites/PLAYBOOK.md` and the site's case file in `docs/client-sites/`.

Client drop boxes (hutsnordic.fi/drop/<token>, admin at /drop/admin/<key>): see `docs/client-sites/DROPBOX.md`.
Never commit a client token or the admin key; this repo is public.
